#About Quiz Zone
Quiz Zone is a free, no-login quiz platform covering topics like Developer/IT, General Knowledge, Math, Science, General Aptitude, Exam Prep, and Interview prep — with more added over time.

There's no database or login here on purpose. Every quiz on this site comes from a single JSON file — new topics and questions are added by simply dropping in a new JSON file, and removed the same way. Nothing else needs to change for a new quiz to show up on the home page.

Who built this
Quiz Zone was built by Vipin Kumar, a Java & Spring Boot developer, using Spring Boot on the backend and Thymeleaf/Bootstrap on the frontend.
